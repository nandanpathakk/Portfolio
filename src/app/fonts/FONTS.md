# Fonts

These font files are served by the site. Both are licensed under the SIL Open
Font License 1.1 (https://openfontlicense.org), which allows bundling them with
a website.

- **Anek Latin** and **Anek Devanagari** (`AnekLatin.woff2`, `AnekDevanagari-name.woff2`)
  by Ek Type. `AnekDevanagari-name.woff2` is a subset containing only the glyphs
  of the name "नंदन पाठक". Source: https://github.com/EkType/Anek
- **Newsreader** (`Newsreader.woff2`, `Newsreader-Italic.woff2`)
  by Production Type. Source: https://github.com/productiontype/Newsreader
